# voyagesync/.github

Organisation-wide defaults for the [voyagesync](https://github.com/voyagesync) repositories.

| File | Used as |
| --- | --- |
| `CODE_OF_CONDUCT.md` | Code of conduct for repositories without their own |
| `MAINTAINERS.md` | Maintainers of the organisation |
| `SECURITY.md` | Security policy for repositories without their own |
| `SUPPORT.md` | Support page for repositories without their own |
| `profile/README.md` | The organisation's profile page |
